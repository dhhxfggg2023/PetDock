# 0.4.2

## 这次改了什么

- **修好「下载更新 / 从市场装插件」**：以前下载器不跟随重定向，而 GitHub 的下载地址必然 302 —— 也就是说这两个按钮在真实网络上从来没成功过。现在只有一个出网通道（写死主机、每跳校验、有体积上限、失败点名主机）。
- **插件市场接进插件页**：插件页顶部「浏览插件市场…」，与本地列表是同一块区域的两种态。
- **搬运工崩溃安全**：覆盖到一半断电/被杀之后，下次启动能把旧版本换回来，而不是既没有旧版本也跑不起来。
- **插件入口只有一个属主**：清单里的 entry 不许把宿主带到插件目录之外。
- **tier-2 进程边界**：宿主死了它跟着死，只许一个进程，内存有上限。
- 更新路径上「读数失败」不再静音；搬运工清理失败写进 helper.log。

## 怎么升级

解压覆盖到原来的目录即可，`data\` 不受影响。或者：面板 → 设置 → 检查更新。

## 已知限制

- tier-2 仍然不是沙箱（能读任意文件、连任意网络），只有生命周期与资源边界。
- 某些被 hosts / 加速器劫持的机器上（包括作者本机），`release-assets.githubusercontent.com` 解析到 127.0.0.1，下载会失败；失败信息现在会点名是哪台主机。
