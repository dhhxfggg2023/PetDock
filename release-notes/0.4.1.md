解压出来的文件夹不再带版本号。

## 改动

zip 仍然带版本（`PetDock-0.4.1-win-x64.zip`），但解压出来的顶层目录固定叫 `PetDock`：

```
PetDock-0.4.1-win-x64.zip
└─ PetDock/
   ├─ PetDock.Core.exe
   ├─ PetDock.Update.exe
   └─ data/
```

## 为什么不只是「少了个装饰」

更新是**原地覆盖**同一个安装目录，文件夹名不参与定位。所以从 0.4.0 升到 0.5.0 之后，
一个还叫 `PetDock-0.4.0` 的文件夹里装的已经是 0.5.0 —— 名字和内容对不上，而且永远不会自愈。

zip 名必须留着版本：你要区分下载哪个包，sha256 核对的是它，更新源地址指向的也是它。

## 说明书里写错的地方

安装目录里的 `INSTALL.md` 原来教的是「解压到新文件夹，把 data 拷过去」—— 那是没有更新功能年代的口径。
照那样做会在旁边留下一个旧版本，而旧版本里有一个会跟当前版本抢单实例锁的 exe。
现在写的是：**覆盖现有文件夹**，或者直接用「检查更新」。
