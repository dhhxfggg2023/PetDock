# 0.4.3

## 这次改了什么

- **装好了、但没能自己开回来，现在会说**：以前这条只剩 `helper.log` 里一行，界面上仍是「已更新到 x.y.z」—— 用户对「刚才桌宠为什么消失」永远没有答案。现在宿主把那次结局说成「已更新到 x.y.z，但没能自动打开，这次是你自己启动的」。
- **「上次的更新意图读不出来」不再等于「没有意图」**：`restart.txt` 在、但读不出来时，以前会被当成「没有更新意图」，于是可能再起一个搬运工去抢同一批文件。现在这一次不装，并把原因说清楚（`ui.update.intentUnreadable`）。
- **覆盖安装失败的残留不再变成一只插件**：`<id>.bak-时间戳` 以前会被当成同 id 的第二只插件装进宿主 —— 用户看到重复项、删掉一只另一只还在，而且再也不会被更新到。现在这类残留被发现逻辑跳过，搬不回去的旧目录进回收站（看得见、拿得回）。
- **装好但没开起来时，旧版本的备份不再被一起删掉**：解出来的那份收掉（几百兆），旧版本那份留到确认新版本真的起来了为止。

## 怎么升级

解压覆盖到原来的目录即可，`data\` 不受影响。或者：面板 → 设置 → 检查更新。

## 已知限制

- tier-2 仍然不是沙箱（能读任意文件、连任意网络），只有生命周期与资源边界。
- 某些被 hosts / 加速器劫持的机器上（包括作者本机），`release-assets.githubusercontent.com` 解析到 127.0.0.1，下载会失败；失败信息会点名是哪台主机。
