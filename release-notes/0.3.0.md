界面上终于能自己检查更新了。

### 亮点

- **设置 → 关于 → 检查更新**：点一下才知道有没有新版本。程序不会在后台偷偷联网 ——
  整个软件只有两处会主动出网（插件市场、检查更新），都是你点了才动，也没有定时器。
- 检查结果分三种，不会糊在一起：有新版本、已是最新、**没查到**（网络不通或更新源不可用）。
  第三种不会说成「已是最新」—— 那会让你在一个其实有更新的版本上永远不再检查。

### 顺带修掉的

- 插件的右键菜单点一次就崩（边枚举边释放条目），表现是「右键宠物的移动 / 暂停 / 移除没用」。
- 插件列表现在每个都有一句「我是干什么的」。
- 宠物大小改成**每只单独调**：想要大猫小老鼠，不用再让全桌一起变。
- 便携版不再往 C 盘写数据。

## 怎么升级

这一版**只能下载、不能自动安装**（自动安装是 0.4.0 才有的能力）。所以升级要手动：

1. 在**设置 → 关于**点「检查更新」，有新版本就会出现「下载新版本」。
2. 下好之后点「打开所在文件夹」，或者用上面那个 zip 的名字自己找。
3. 解压得到新文件夹，把**旧文件夹里的 `data\`** 整个拷进新文件夹。

`data\` 里是你的宠物与设置，不拷的话新版本会当成第一次运行。
拷完旧文件夹就可以删了。
