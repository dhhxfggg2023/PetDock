# PetDock —— 解压即用

这个文件夹就是全部。不需要安装、不需要管理员、不写注册表、不碰系统目录。

## 怎么用

1. 解压 `PetDock-<版本>-win-x64.zip`，得到 `PetDock` 这一个文件夹。
2. 双击里面的 `PetDock.Core.exe`。

第一次会弹「Windows 已保护你的电脑」—— **这不是报错**。程序没有代码签名，包又是从网上下载的，
SmartScreen 对「没签名 + 没人运行过」的文件一律先拦一下。点「更多信息 → 仍要运行」就能开。

想让它以后不再问，在这个文件夹里运行一次（和属性页里的「解除锁定」是同一件事）：

```powershell
Get-ChildItem -Recurse | Unblock-File
```

`PetDock.Update.exe`（更新时用来换文件的那个搬运工）同样带这个标记 —— 要么两个 exe 各点一次
「仍要运行」，要么跑上面这一条，后者更省事。

文件夹名**不带版本号**，这是有意的：升级是原地覆盖这个文件夹（见下），
名字里要是写着版本，升完级它就和里面装的东西对不上了。要认版本看设置页「关于」。

就这样。想放到桌面、D 盘、U 盘都行 —— 整个文件夹可以整体搬走，搬到哪都能跑。

## 你的东西在哪

全在这个文件夹里：

| 路径 | 是什么 |
| --- | --- |
| `data\pets.json` | 导入过哪些宠物、当前选中哪个 |
| `data\packs\` | 你导入的素材（是从原目录复制进来的副本，原目录删掉不影响） |
| `data\state\` | 每个实例的运行时状态（位置、大小等） |

这个落点由文件夹里的 `petdock.portable` 标记决定。**如果删掉这个标记**，数据会改存到
`%LOCALAPPDATA%\PetDock`，适合把程序放进只有读权限的目录（如 `Program Files`）。

## 怎么卸载

删掉这个文件夹。没有别的地方留过痕迹 —— 没有注册表键、没有开始菜单项、没有服务。

删之前如果想把宠物带走，把 `data\` 整个拷出来即可。

## 升级

设置 → 关于 → **检查更新** → **下载新版本**，然后二选一：

- **立即重启更新** —— 程序自己退出、换掉文件、再开回来，面板会重新打开。
- **稍后更新** —— 只记下来；你下次自己点开 PetDock 时它先装好再启动。

两种都是**原地覆盖**同一个 `PetDock` 文件夹，`data\` 不受影响，不用搬任何东西。

也可以手动升级：下载新的 zip，把它解压到**现有文件夹上面**（覆盖），`data\` 会原样保留。
不要解压到一个新文件夹再把 `data\` 搬过去 —— 那会在旁边留下一个旧版本。

## 已知限制

- 只支持 64 位 Windows（`win-x64`）。包里不含 ARM64 / Windows 7 的运行时。
- 没有代码签名：第一次运行会弹 SmartScreen，见上面「怎么用」第 2 步。
- 没有安装器、没有 MSI、没有开始菜单图标 —— 这是刻意的（RFC-25 §3.4）。

## 排错

| 现象 | 原因与做法 |
| --- | --- |
| 双击没反应 | 检查是否解压在只读位置；把文件夹移到 `D:\` 或桌面再试 |
| 启动后立刻退出 | 从命令行运行 `PetDock.Core.exe` 看报错文本 |
| 宠物不见 / 状态丢了 | 确认 `data\pets.json` 还在；确认没删 `petdock.portable` 标记 |
| SmartScreen 拦截 | 未签名 + 文件带着「来自互联网」的标记，见「怎么用」第 2 步；一条 `Get-ChildItem -Recurse \| Unblock-File` 可长期免打扰 |
